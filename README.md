# Data Science Projects – MIASHS

Bienvenue sur mon GitHub !  
Ce repository regroupe les principaux projets réalisés durant ma licence MIASHS (Mathématiques et Informatique appliquées aux Sciences Humaines et Sociales).

##  À propos
Étudiante en data science, je m’intéresse à l’analyse de données, au machine learning et aux méthodes expérimentales.  
J’aime travailler sur des données réelles et construire des solutions basées sur les données.

## Projets

### Système de recommandation agricole
Développement d’un système d’aide à la décision basé sur des données météorologiques, de sol et de saisonnalité.  
→ Modélisation de base de données + logique de recommandation + modèles prédictifs.

### Analyse de données socio-économiques
Analyse et visualisation de données européennes (PIB, temps de travail, congés).  
→ Python (Matplotlib, Seaborn, GeoPandas).

### Projet de psychologie expérimentale
Étude des mécanismes cognitifs via une tâche expérimentale basée sur les temps de réaction.  
→ Analyse statistique et interprétation des résultats.

### Analyse des Jeux Olympiques
Création d’une base de données et analyse statistique (ANOVA, khi²) pour identifier les facteurs de performance.

### Projet web – plateforme scientifique
Développement d’un site web permettant de visualiser des données scientifiques.

## Compétences
- Python (Pandas, Matplotlib, Seaborn)
- SQL (MySQL)
- R (analyse statistique)
- Visualisation de données
- Machine learning (bases)
- Conception expérimentale

## Objectif
Développer des compétences avancées en data science et travailler sur des projets d’analyse et de modélisation de données.
